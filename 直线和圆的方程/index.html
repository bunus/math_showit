用方程研究直线与圆

解析几何的基本思路是：把几何对象放进坐标系，用方程表示，再通过代数运算得到几何结论。下面按八节内容整理公式、判定方法与常见易错点。

直线由方向与一个点确定，圆由圆心与半径确定。位置关系、距离、弦长，最终都归结为方向向量、法向量与点到直线的距离。

d = |Ax₀ + By₀ + C| / √(A² + B²)
01

倾斜角与斜率

k = tan α

α ∈ [0°, 180°)；α = 90° 时斜率不存在。过两点 P₁、P₂ 的斜率 k = (y₂−y₁)/(x₂−x₁)（x₁≠x₂）。

02

直线方程

y − y₀ = k(x − x₀)

点斜式、斜截式、两点式、截距式、一般式。前四种都有限制，一般式 Ax+By+C=0（A、B 不同时为 0）可表示所有直线。

03

位置关系

A₁A₂ + B₁B₂ = 0

一般式下：平行 ⇔ A₁B₂−A₂B₁=0 且不重合；垂直 ⇔ A₁A₂+B₁B₂=0。斜率式结论只在两条直线斜率都存在时适用。

04

距离公式

d = |C₁−C₂| / √(A²+B²)

点到直线用一般式代入；两平行线必须先把 x、y 的系数化成相同，再代入截距差。

05

圆的方程

(x−a)² + (y−b)² = r²

一般式 x²+y²+Dx+Ey+F=0，当 D²+E²−4F>0 时表示圆，圆心 (−D/2, −E/2)，半径 ½√(D²+E²−4F)。

06

直线与圆

l = 2√(r² − d²)

比较圆心到直线的距离 d 与半径 r：d<r 相交，d=r 相切，d>r 相离。相交时弦长由垂径定理得到。

07

圆与圆

|r₁−r₂| ≤ d ≤ r₁+r₂

用圆心距 d 与 r₁+r₂、|r₁−r₂| 比较，得到外离、外切、相交、内切、内含五种位置关系。

08

圆的切线

|PT| = √(|PC|² − r²)

过圆外一点有两条切线，切线长相等，且 PT ⊥ CT。切点弦可由圆与以 PC 为直径的圆相交得到。

常见易错点

  • 倾斜角不是 arctan k。α 的范围是 [0°, 180°)，α = 90° 时斜率不存在，不能用 k 表示。
  • 截距不是距离。横截距、纵截距都是坐标，可以为负；截距式要求两个截距都不为 0。
  • 斜率判定有前提。k₁=k₂ ⇒ 平行（或重合）只适用于斜率都存在的情形；一般式判定更通用。
  • 距离公式先化一般式。使用 d = |Ax₀+By₀+C|/√(A²+B²) 前，要保证 A、B 不同时为 0。
  • 圆的一般方程要验判别式。D²+E²−4F>0 才是圆，等于 0 是一个点，小于 0 不表示图形。
  • 两圆方程相减得到的是公共弦所在直线（或根轴），不是公共弦的长度。

课堂演示路线

  1. 01 拖动 A、B，观察 α 从 0° 到 180° 时 k 的符号与大小；停在 90° 说明斜率不存在。
  2. 02 切换五种方程形式，同一条直线换一种写法，强调各自成立的条件。
  3. 03 依次摆出平行、垂直、相交、重合，比较方向向量与法向量。
  4. 04 拖动 P 看距离变化，再切换两平行线，验证“系数相同再作差”。
  5. 05 由标准方程展开到一般方程，再把判别式调成 0 与负数。
  6. 06 扫描直线，连续观察相交 → 相切 → 相离与弦长变化。
  7. 07 移动圆心，依次经过五种位置关系，观察公共弦的出现与消失。
  8. 08 拖动 P，验证两条切线长相等、PT ⊥ CT，并打开辅助圆看切点弦。

点到直线距离的由来

设直线 l: Ax+By+C=0，P(x₀,y₀)。取 l 的法向量 n=(A,B)，在 l 上任取一点 Q，则 P 到 l 的距离等于向量 QP 在 n 方向上投影的绝对值：

d = |n·QP| / |n| = |A(x₀−x_Q)+B(y₀−y_Q)| / √(A²+B²) = |Ax₀+By₀+C| / √(A²+B²)

圆的切线与切点弦

圆 C: (x−a)²+(y−b)²=r²，圆外一点 P。切线长 |PT|=√(|PC|²−r²)；两个切点 T₁、T₂ 满足 CT₁⊥PT₁、CT₂⊥PT₂。

以 PC 为直径的圆与圆 C 的两个交点正是 T₁、T₂；两圆方程相减，即得切点弦 T₁T₂ 所在直线。
