统一定义：|PF| / d(P, ℓ) = e
Equation Atlas · 方程速查

一个比值，三种曲线

把“到定点的距离”与“到定直线的距离”作比，比值 e 就是离心率。e 小于、等于、大于 1，分别得到椭圆、抛物线、双曲线。下面把定义、标准方程与推导一次讲清。

设动点 P 到焦点 F 的距离为 r，到一条定直线 ℓ（准线）的距离为 d。若 r / d = e 为常数，则 P 的轨迹是圆锥曲线。
焦点、准线、离心率三个对象，统一了椭圆、抛物线和双曲线。

PF / d(P, ℓ) = e
0 < e < 1

椭圆

x²/a² + y²/b² = 1

a > b > 0，c² = a² − b²，e = c/a。焦点在 x 轴：F(±c, 0)；在 y 轴时交换 x、y。

另一种定义：|PF₁| + |PF₂| = 2a。

e > 1

双曲线

x²/a² − y²/b² = 1

a,b > 0，c² = a² + b²，e = c/a。焦点在 x 轴：F(±c, 0)；渐近线 y = ±(b/a)x。

另一种定义：| |PF₁| − |PF₂| | = 2a。定义含绝对值，所以轨迹是两支。

e = 1

抛物线

y² = 2px

p > 0，焦点 F(p/2, 0)，准线 x = −p/2。也有定义 |PF| = d(P, ℓ)。

开口向上时标准方程为 x² = 2py。

椭圆方程的由来

设 F₁(−c,0)、F₂(c,0)，由 |PF₁| + |PF₂| = 2a 移项并平方：

√((x+c)²+y²) + √((x−c)²+y²) = 2a

两次平方后得到 (a²−c²)x² + a²y² = a²(a²−c²)。令 b² = a²−c²，即得 x²/a² + y²/b² = 1。

双曲线方程的由来

把“和”换成“差的绝对值” | |PF₁| − |PF₂| | = 2a，同样移项、平方，整理可得：

(a²−c²)x² + a²y² = a²(a²−c²)，但此时 c > a，所以令 b² = c²−a²，得到 x²/a² − y²/b² = 1。

椭圆中 a 最大；双曲线中 c 最大，这是两个关系式最容易混淆的地方。

抛物线方程的由来

焦点 F(p/2,0)，准线 x = −p/2，由 |PF| = d(P,ℓ)：

√((x−p/2)² + y²) = x + p/2

两边平方并整理，x² 项抵消，得到 y² = 2px。这也是抛物线的焦点到顶点距离为 p/2 的原因。

统一定义的极坐标形式

以焦点为极点、极轴沿对称轴，设半通径为 ℓ，准线在焦点左侧，则轨迹满足：

r = ℓ / (1 − e cos θ)

e < 1 时是椭圆；e = 1 时是抛物线；e > 1 时是双曲线。按定义，两支上的点到同一焦点、同一准线的距离比都等于 e；取 r > 0 作图时只描出含焦点的一支，图中另一支由中心对称补画。

看方程判类型（无 xy 项时）

把方程写成 Ax² + Cy² + Dx + Ey + F = 0：

  • A、C 同号：椭圆型（A=C 且无平移时为圆）；
  • A、C 异号：双曲线型；
  • A、C 中恰有一个为 0：抛物线型。

有平移时先配方，化成以 (h,k) 为中心或顶点的标准形式再判断。

五个易错点

  • 椭圆 a² = b² + c²，a 最大；双曲线 c² = a² + b²，c 最大。
  • y² = 2px 的焦点是 (p/2,0)，不是 (p,0)；准线 x = −p/2。
  • 离心率 e 的范围：椭圆 0 ≤ e < 1（圆 e=0），双曲线 e > 1，抛物线 e=1。
  • 焦点轴换到 y 轴时，方程与焦点坐标要同时交换 x、y，不能只改方程。
  • 极坐标 r = ℓ/(1−e cosθ) 在 e > 1 且 r > 0 时只画出双曲线的一支，不能把“定义”说成“只给一支”。

课堂演示路线

① 先固定椭圆 a，只改变 e：观察 e 越接近 0，椭圆越接近圆。

② 切到双曲线，观察 c² = a² + b² 与渐近线如何同时变化。

③ 切到抛物线，验证 |PF| 与到准线的距离始终相等。

④ 最后进入“统一视角”，让 e 从 0.6 调到 1.6，看三类曲线如何由同一个焦点—准线定义生成。
