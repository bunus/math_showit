## 0. 结论速览

| 问题 | 核验结论 |
|---|---|
| 椭圆 c=ae、b=a√(1-e²)、准线 x=±a²/c | ✅ 正确 |
| 双曲线 c=ae、b=a√(e²-1)、准线 x=±a²/c、渐近线 y=±(b/a)x（水平） | ✅ 正确 |
| 抛物线 y²=2px：焦点 (p/2,0)、准线 x=-p/2、e=1 | ✅ 正确 |
| 统一视角（F 在原点、准线 x=-l/e、θ 从 +x 起算）的极坐标方程 | ✅ 是 r = l/(1-e·cosθ)（负号），不是 1+e·cosθ |
| 统一视角直角坐标方程 | ✅ √(x²+y²) = l + e·x，即 (1-e²)x² + y² - 2elx - l² = 0 |
| l 是否半通径（semi-latus rectum） | ✅ 是；椭圆/双曲线 l=b²/a，抛物线 l=p；且 l = e·d(F,准线) |
| e>1 时“只有双曲线的一支” | ⚠️ **仅对极坐标 r>0 的绘图成立**；按定义（距离比取绝对值）轨迹是**整条双曲线（两支）**，见 §5.5 |
| e=0 | ⚠️ 圆；准线 x=±a²/c 无定义（在无穷远），页面必须特判，避免除零 |
| 竖直焦点轴 | ✅ 交换 x/y 即可；注意双曲线渐近线斜率变为 ±a/b，焦半径变为 a±e·y（椭圆） |

## 1. 坐标约定与页面实现约定

1. **坐标系**：平面直角坐标系，x 轴向右、y 轴向上；角度 θ 从 +x 轴起算、逆时针为正；长度单位任意。
2. **画布**：Canvas 的屏幕坐标 y 轴向下，必须显式翻转；并且 **x、y 必须使用同一比例尺**：

        x_screen = cx + k * x
        y_screen = cy - k * y        (k > 0, kx = ky)

   **等比例是硬性要求**：若 x/y 比例不同，离心率、焦点位置、准线距离、渐近线倾角都会视觉失真，学生会“看”到错误结论。
3. **三套原点约定**（页面必须标注，避免跨模式误读）：
   - 模式 A 椭圆、模式 B 双曲线：**中心在原点**，方程为标准形式 x²/a² ± y²/b² = 1；
   - 模式 C 抛物线：**顶点在原点**，方程为 y²=2px（或 x²=2py）；
   - 模式 D 统一视角：**焦点 F 在原点**，极坐标方程最简洁。

   四套图切换时原点的物理含义不同，建议在画布左下角显示“当前原点：中心/顶点/焦点”。
4. **符号**：本文用 l 表示半通径（semi-latus rectum），d 表示焦点到相应准线的距离，c 为半焦距，e 为离心率。

## 2. 椭圆

### 2.1 定义与标准方程

**定义**：平面内到两定点 F₁、F₂ 的距离之和等于常数 2a（2a > |F₁F₂| = 2c）的点的轨迹。
设中心在原点、焦点在 x 轴上，则

        x²/a² + y²/b² = 1        (a > b > 0)

其中 a 为长半轴、b 为短半轴、c=√(a²-b²) 为半焦距，焦点 F₁(-c,0)、F₂(c,0)。

**竖直焦点轴（长轴竖直）**：交换 x、y：

        x²/b² + y²/a² = 1        (a > b > 0)

焦点 (0,-c)、(0,c)；长轴端点 (0,±a)；短轴端点 (±b,0)。

### 2.2 参数关系与几何量（水平焦点轴）

| 量 | 公式 | 备注 |
|---|---|---|
| 半焦距 | c = a·e = √(a²-b²) | 焦点 (±c, 0) |
| 短半轴 | b = a·√(1-e²) | 由 a²=b²+c² 得 |
| 离心率 | e = c/a = √(1-b²/a²)，范围 0 ≤ e < 1 | e=0 为圆 |
| 顶点 | (±a,0)；短轴端点 (0,±b) | 长轴长 2a，短轴长 2b |
| 准线 | x = ±a²/c = ±a/e | e=0 时不存在（在无穷远） |
| 半通径 | l = b²/a = a(1-e²) | 焦点弦半长；通径长 2b²/a = 2l |
| 焦准距 | d = a²/c - c = b²/c = l/e | 焦点到同侧准线的距离 |
| 焦半径 | 左焦点：PF₁ = a + e·x；右焦点：PF₂ = a - e·x | 竖直时 a ± e·y（下焦点取 +） |
| 定义不变量 | PF₁ + PF₂ = 2a | 任意点皆成立 |

### 2.3 推导要点（由定义到标准方程）

设 P(x,y)，F₁(-c,0)、F₂(c,0)，由 |PF₁|+|PF₂|=2a 得

        √((x+c)²+y²) + √((x-c)²+y²) = 2a

移项、平方两次，整理得 (a²-c²)x² + a²y² = a²(a²-c²)。令 b²=a²-c²>0，即得 x²/a²+y²/b²=1。
关键点：**必须 a>c（即 0≤e<1）轨迹才非退化**；a=c 退化为线段 F₁F₂，a<c 无轨迹。

反向验证（更常用于讲评）：对标准方程上的点，
|PF₁| = a + ex，|PF₂| = a - ex，相加为 2a，且 |PF₁| 与到准线 x=-a/e 的距离之比为 e。

### 2.4 焦点—准线视角与焦半径

椭圆有**两对**焦点—准线：F₁(-c,0) ↔ x=-a/e，F₂(c,0) ↔ x=+a/e，且对椭圆上任意点

        PF₁ / dist(P, x=-a/e) = e,    PF₂ / dist(P, x=+a/e) = e.

### 2.5 动画参数化（稳健写法）

水平椭圆：

        P(t) = (a·cos t,  b·sin t),   t ∈ [0, 2π)

竖直椭圆：

        P(t) = (b·cos t,  a·sin t),   t ∈ [0, 2π)

- 无除零、无定义域问题；闭合曲线，首尾相接（采样 601～1201 点即可平滑）。
- 若要从焦点出发按极角动画（模式 D 的讲法）：以焦点为极点、极轴指向外侧（背离对应准线），
  r = l/(1 - e·cosθ)，θ∈[0,2π)，e<1 时 r 恒正（分母 ≥ 1-e > 0），无需裁剪。
- 动点标记建议用参数 t 驱动；PF₁、PF₂ 用两点间距离实时计算（hypot），标签值再与解析公式核对，避免“公式值”和“画出的点”不一致。
- 页面显示“焦半径 a±ex”时，注意 x 是**点在标准坐标系中的横坐标**（竖直模式换 y），不是屏幕坐标。

### 2.6 竖直焦点轴对照

| 项目 | 水平焦点轴 | 竖直焦点轴 |
|---|---|---|
| 方程 | x²/a²+y²/b²=1 | x²/b²+y²/a²=1 |
| 焦点 | (±c,0) | (0,±c) |
| 长轴端点 | (±a,0) | (0,±a) |
| 准线 | x=±a²/c | y=±a²/c |
| 焦半径 | a ± e·x | a ± e·y（下焦点 +，上焦点 -） |

### 2.7 常见错误

1. 把椭圆的 c 当成最大量：椭圆 a²=b²+c²（a 最大）；双曲线 c²=a²+b²（c 最大）。
2. 准线写成 x=±a²/b 或 ±a/c：应为 ±a²/c（= ±a/e）。
3. 竖直椭圆仍写 a±e·x：应为 a±e·y。
4. e=0 时仍强行画准线并计算 a²/c，得到 Infinity/NaN。
5. 把“通径”与“半通径”混为一谈：通径长 2b²/a，半通径 l=b²/a。

## 3. 双曲线

### 3.1 定义与标准方程

**定义**：平面内到两定点 F₁、F₂ 的距离之差的绝对值等于常数 2a（0 < 2a < |F₁F₂| = 2c）的点的轨迹。
中心在原点、焦点在 x 轴上：

        x²/a² - y²/b² = 1        (a > 0, b > 0)

c = √(a²+b²)，焦点 (±c,0)，顶点 (±a,0)。

**竖直实轴**：交换 x、y：

        y²/a² - x²/b² = 1

焦点 (0,±c)，顶点 (0,±a)。

### 3.2 参数关系与几何量（水平实轴）

| 量 | 公式 | 备注 |
|---|---|---|
| 半焦距 | c = a·e = √(a²+b²) | 焦点 (±c,0) |
| 虚半轴 | b = a·√(e²-1) | 由 c²=a²+b² 得 |
| 离心率 | e = c/a = √(1+b²/a²) > 1 | 恒大于 1 |
| 顶点 | (±a,0) | 实轴长 2a，虚轴长 2b |
| 准线 | x = ±a²/c = ±a/e | 两条，位于顶点与中心之间侧 |
| 渐近线 | y = ±(b/a)·x | 水平实轴 |
| 半通径 | l = b²/a = a(e²-1) | 通径长 2b²/a = 2l |
| 焦准距 | d = c - a²/c = b²/c = l/e | 焦点到同侧准线 |
| 焦半径 | 左焦点：PF₁ = abs(e·x+a)；右焦点：PF₂ = abs(e·x-a) | 竖直时 abs(e·y±a) |
| 定义不变量 | abs(PF₁ - PF₂) = 2a | 必须带绝对值 |

### 3.3 推导要点

由 abs(|PF₁|-|PF₂|) = 2a（2a<2c），移项平方两次得 (c²-a²)x² - a²y² = a²(c²-a²)；令 b²=c²-a²>0，得 x²/a²-y²/b²=1。
关键点：
- 2a<2c 即 a<c，等价于 e>1；
- 2a=2c 退化为两条射线（x≤-a 与 x≥a 在 x 轴上的外部射线）；
- 2a>2c 无轨迹；
- 两点的**距离差的绝对值**去掉绝对值只得到一支。

### 3.4 渐近线与“两支”

- 水平实轴：渐近线 y=±(b/a)x；竖直实轴：**y=±(a/b)x**（斜率为 a/b，不是 b/a！）。
- 双曲线定义是“差的绝对值”，本身包含两支；方程 x²/a²-y²/b²=1 中 x≥a 为右支、x≤-a 为左支。
- 若用参数化只画一支：右支 (a·cosh u, b·sinh u)，左支 (-a·cosh u, b·sinh u)，u∈ℝ。
- 焦点—准线：两对 F₁(-c,0) ↔ x=-a/e、F₂(c,0) ↔ x=+a/e；对**两支上任意点**，到任一对焦点/准线的距离比都等于 e（这正是“定义轨迹是整条双曲线”的原因，见 §5.5）。

### 3.5 动画参数化（稳健写法）

水平双曲线：

        右支: P(u) = ( a·cosh u,  b·sinh u)
        左支: P(u) = (-a·cosh u,  b·sinh u),   u ∈ [-U, U]

竖直双曲线：

        上支: P(u) = ( b·sinh u,  a·cosh u)
        下支: P(u) = ( b·sinh u, -a·cosh u),   u ∈ [-U, U]

- 无除零问题；cosh 增长快，建议 U ≤ 4～5，并按视口裁剪：取
  U = min( arcosh(x_max/a), arsinh(y_max/b) )（水平；x_max、y_max 为视口半宽/半高对应的世界坐标），
  避免坐标过大导致线条抖动。
- 画图顺序建议：先画渐近线（虚线）→ 再画曲线 → 再画焦点/准线/顶点/动点。
- 注意：e→1⁺ 时 b=a√(e²-1)→0，双曲线越来越“扁”；而若固定 l=b²/a 让 e→1，则 a、b、c 同时发散（见 §5.8），两种参数化要区分。

### 3.6 竖直实轴对照

| 项目 | 水平实轴 | 竖直实轴 |
|---|---|---|
| 方程 | x²/a²-y²/b²=1 | y²/a²-x²/b²=1 |
| 焦点 | (±c,0) | (0,±c) |
| 顶点 | (±a,0) | (0,±a) |
| 准线 | x=±a²/c | y=±a²/c |
| 渐近线 | y=±(b/a)x | y=±(a/b)x |
| 焦半径 | abs(e·x±a) | abs(e·y±a) |

### 3.7 常见错误

1. c²=a²+b² 记成 c²=a²-b²（与椭圆混淆）。
2. 竖直实轴仍用 y=±(b/a)x 当渐近线（应为 ±(a/b)x）。
3. 定义漏掉绝对值，导致只画一支却声称“双曲线”。
4. 焦半径不加绝对值，在错误的一支上出现负距离。
5. 认为 e 越大越“圆”：双曲线 e 越大开口越张开。

## 4. 抛物线

### 4.1 定义与标准方程

**定义**：到定点 F 与到定直线 ℓ 距离相等的点的轨迹（e=1）。
顶点在原点、开口向右：

        y² = 2p·x        (p > 0)

焦点 F(p/2, 0)，准线 x = -p/2，顶点 (0,0)，对称轴 x 轴。
开口向上：

        x² = 2p·y        (p > 0)

焦点 F(0, p/2)，准线 y = -p/2。

### 4.2 几何量

| 量 | 公式 | 备注 |
|---|---|---|
| 焦点 | (p/2,0)（或 (0,p/2)） | 不是 (p,0)！ |
| 准线 | x=-p/2（或 y=-p/2） | 与焦点分居顶点两侧 |
| 离心率 | e = 1 | |
| 焦准距 | p | 焦点到准线的距离 |
| 通径 | 2p | 过焦点垂直于对称轴的弦 |
| 半通径 | l = p | 与统一视角的 l 一致 |
| 焦半径 | PF = x + p/2（竖直 y + p/2） | 也等于到准线距离 |
| 定义不变量 | PF / dist(P,准线) = 1 | |

### 4.3 推导要点

设焦点 F(p/2,0)、准线 x=-p/2，由 |PF| = dist(P,ℓ)：

        √((x-p/2)²+y²) = abs(x+p/2)

两边平方整理得 y² = 2px。p 的几何意义：**焦点到准线的距离（焦准距）**；半通径 l=p。

### 4.4 动画参数化（稳健写法）

水平抛物线：

        P(t) = (p·t²/2,  p·t),   t ∈ ℝ

竖直抛物线：

        P(t) = (p·t,  p·t²/2),   t ∈ ℝ

- 无除零；|t| 按视口裁剪：水平时 |t| ≤ min(√(2x_max/p), y_max/p)。
- 也可用 x = y²/(2p) 直接按 y 采样（等价，注意 p>0）。
- 极坐标（焦点为极点、极轴 +x）：r = p/(1-cosθ)，θ∈(0,2π)，θ=0 处 r→∞（开口方向），绘图需裁剪。

### 4.5 常见错误

1. 焦点写成 (p,0) 或准线写成 x=-p：应为 (p/2,0)、x=-p/2。
2. 把 p 当成通径：通径是 2p，半通径是 p。
3. x²=2py 与 y²=2px 的焦点/准线互换时忘换坐标轴。
4. 认为抛物线有两条准线/两个焦点（只有一对）。
5. 开口方向与 p 的符号：标准形式约定 p>0；若写 y²=-2px（p>0）则开口向左，焦点 (-p/2,0)、准线 x=p/2。

## 5. 统一焦点—准线视角（模式 D）

### 5.1 设置

取**焦点 F 在原点**，**准线 ℓ：x = -l/e**（l>0, e>0），动点 P 满足

        |PF| = e · dist(P, ℓ).

记 d = dist(F,ℓ) = l/e。焦点到准线的距离 d 与 l 的关系为 l = e·d。

### 5.2 极坐标方程（符号已核对）

令 P = (r·cosθ, r·sinθ)（r=|PF|≥0，θ 从 +x 轴起算）。P 到 ℓ 的距离为

        dist(P,ℓ) = abs(x_P + l/e) = abs(r·cosθ + l/e).

代入定义 r = e·abs(r·cosθ + l/e)。**在焦点所在一侧**（即 x > -l/e，此时 r·cosθ + l/e ≥ 0）：

        r = e·(r·cosθ + l/e)  ⇒  r(1 - e·cosθ) = l

故

        r = l / (1 - e·cosθ)        （θ 从 +x 轴起算，准线在 x = -l/e）

**最终答案：是 r = l/(1-e·cosθ)，不是 1+e·cosθ。** 若准线改到 x=+l/e，则同一推导得 r = l/(1+e·cosθ)；符号随准线所在侧而变。若 θ 从 −x 轴起算，则 cos 换成 −cos。

在准线**另一侧**（x < -l/e，r·cosθ + l/e < 0）解同一方程，得

        r = -l / (1 + e·cosθ)        （仅当 1+e·cosθ<0 时有 r>0）

- 当 0<e≤1：1+e·cosθ ≥ 1-e ≥ 0，第二式无正解，**第一式即完整轨迹**；
- 当 e>1：第二式给出**另一支**（见 §5.5）。

### 5.3 直角坐标方程

由 r = l + e·x（焦点侧）得

        √(x²+y²) = l + e·x

两边平方：

        (1 - e²)x² + y² - 2e·l·x - l² = 0

这就是统一视角的直角坐标方程（焦点侧一支）。注意：它对 e=0 也成立（圆 x²+y²=l²）。若保留绝对值 √(x²+y²) = abs(l + e·x)，则 e>1 时得到**整条双曲线**。

### 5.4 e 的三种情形（由方程 5.3 配方得到）

| e | 曲线 | a | b | c=ae | 中心 | 焦点 | 准线 | 半通径 l | 极坐标 r>0 画出的部分 |
|---|---|---|---|---|---|---|---|---|---|
| 0<e<1 | 椭圆 | l/(1-e²) | l/√(1-e²) | e·l/(1-e²) | (c,0) | (0,0)、(2c,0) | x=-l/e、x=c+a/e | b²/a | **完整椭圆** |
| e=1 | 抛物线 | —（p=l） | — | — | 顶点 (-l/2,0) | (0,0) | x=-l | p=l | **完整抛物线** |
| e>1 | 双曲线 | l/(e²-1) | l/√(e²-1) | e·l/(e²-1) | (-c,0) | (0,0)、(-2c,0) | x=-l/e、x=-c-a/e | b²/a | **含焦点一侧的一支** |
| e=0 | 圆 | l | l | 0 | (0,0) | (0,0) | 无（在无穷远） | l（=半径） | 完整圆 |

补充推导：
- e<1：配方得 (x-c)²/a² + y²/b² = 1，其中 a=l/(1-e²)、b=l/√(1-e²)、c=el/(1-e²)；a²=b²+c²；F 是**左焦点**，第二个焦点 F'=(2c,0)，第二条准线 x=c+a/e。
  - 椭圆在统一视角下的 x 范围：[c-a, c+a] = [-l/(1+e), l/(1-e)]（e→1⁻ 时右端 →∞，见 §5.8）。
- e=1：y² = 2l·x + l² = 2l·(x+l/2)，顶点 (-l/2,0)，焦点仍为原点，准线 x=-l；与标准形式的关系：p=l。
- e>1：配方得 (x+c)²/a² - y²/b² = 1，a=l/(e²-1)、b=l/√(e²-1)、c=el/(e²-1)；c²=a²+b²；F 是**右焦点**，第二个焦点 F'=(-2c,0)，第二条准线 x=-c-a/e；渐近线 y=±(b/a)(x+c)=±√(e²-1)·(x+c)。
  - 右支顶点 (-c+a,0) = (-l/(e+1),0)；左支顶点 (-c-a,0) = (-l/(e-1),0)。

**与标准形式（中心/顶点在原点）的对应关系**（页面展示“标准方程”时必须换坐标）：

| 统一视角 | 平移 | 标准形式 |
|---|---|---|
| 椭圆 (x-c)²/a²+y²/b²=1 | X = x-c | X²/a²+y²/b²=1 |
| 抛物线 y²=2l(x+l/2) | X = x+l/2 | y²=2lX（p=l） |
| 双曲线 (x+c)²/a²-y²/b²=1 | X = x+c | X²/a²-y²/b²=1 |

### 5.5 e>1 的分支问题（**重点**）

这是模式 D 最容易被表述错的地方，必须区分两种说法：

**(A) 极坐标作图（页面实际画的东西）**

r = l/(1-e·cosθ) 取 r>0 时：
- 定义域要求 1 - e·cosθ > 0，即 cosθ < 1/e，θ ∈ (arccos(1/e), 2π-arccos(1/e))；
- 得到的点满足 x = r·cosθ > -l/e，即**全部在准线含焦点的一侧**；
- 因此只画出双曲线中**与焦点同处准线一侧的那一支**（上表中为“右支”，其顶点为 (-l/(e+1),0)）。
- 结论：**“e>1 时 r=l/(1-e·cosθ) 只得到一支”是对的**（这是绘图事实）。

**(B) 焦点—准线定义（数学轨迹）**

定义 |PF| = e·dist(P,ℓ) 中的距离是**绝对值**。对 e>1，把方程改写成 √(x²+y²) = abs(l+e·x)，两边平方后与 (A) 的平方方程完全相同，即**两支都满足同一焦点 F、同一准线 ℓ 的距离比 e**。
数值例子（e=2, l=1，即预设 U3）：左支点 P=(-1,0) 到 F 的距离为 1，到准线 x=-0.5 的距离为 0.5，比值恰为 2。
- 结论：**按定义，轨迹是整条双曲线（两支）**；verify.py 对标准双曲线两支抽样，比值误差 < 1e-12。

**另一支怎么得到**（三种等价说法，页面可选其一）：

1. **另一个焦点/准线**：F'=(-2c,0)、ℓ': x=-c-a/e；以 F' 为极点、极轴指向背离 ℓ' 的方向（即 −x 方向）时，极坐标方程形式不变：r=l/(1-e·cosφ)。两条支各自“自带”一对焦点/准线。
2. **中心对称**：两支关于中心 (-c,0) 中心对称。把第一支上的点 (x,y) 映射为 (-2c-x, -y) 即得第二支。这是页面补画第二支最稳妥的方法（无需第二套极坐标）。
3. **同一 F、ℓ 下的第二解**：在准线另一侧，r = -l/(1+e·cosθ)（θ 为同一极角，取使 r>0 者）。它与第一支是同一双曲线的两支，但极坐标形式不同，**不建议作为教学主叙述**。

**教学文案（可直接采用）**：

> “到焦点 F 的距离与到准线 ℓ 的距离之比为 e：0<e<1 时是椭圆，e=1 时是抛物线，e>1 时是双曲线。双曲线有两支，两支上的点到**同一对**焦点/准线的距离比都等于 e。”
>
> “在焦点为极点的极坐标中，若准线在 x=-l/e，方程统一为 r=l/(1-e·cosθ)。取 r>0 时，e>1 的这个方程只画出与焦点同侧的那一支；另一支在准线另一侧，需要用它自己的焦点/准线（或关于中心作对称）补画。”

**不要使用**的表述：

- ❌ “e>1 时定义只得到双曲线的一支。”——与定义（距离比）矛盾；
- ❌ “另一支是‘假的’/不满足距离比。”——两支都满足；
- ❌ “极坐标方程在 e>1 时描绘整条双曲线。”——只描绘一支。

### 5.6 l 的几何意义与标准形式关系

**l 就是半通径（semi-latus rectum）**：

- 过焦点 F、垂直于焦点轴的弦（通径）长度为 2l，半长为 l。
- 统一视角下（焦点在原点、轴水平），该弦所在直线为 x=0，与曲线交点恒为 (0, ±l)（对任意 e>0 都成立）；这是 l 的“可视”定义，也是页面动画最好的 l 展示方式。
- 与标准形式的关系：
  - 椭圆：l = b²/a = a(1-e²)；
  - 双曲线：l = b²/a = a(e²-1)；
  - 抛物线：l = p（标准形式 y²=2px 中的 p，亦即焦准距）；
  - 圆（e=0）：l = a = 半径。
- 统一关系：a = l/abs(1-e²)（e≠1）；d = dist(F,ℓ) = l/e；e = c/a。

### 5.7 e=0 的边界

- e=0 时 c=ae=0，两焦点重合为圆心，曲线为圆 x²+y²=l²（半径 l）；
- 准线 x=-l/e **不存在**（在无穷远），标准模式下的准线 x=±a²/c 也因 c=0 无定义；
- 页面必须特判：e=0 时隐藏准线，或显示“准线在无穷远（e=0 时不存在）”；**绝不能**直接算 a²/c 或 l/e（会得到 Infinity/NaN）。
- 同理，e 滑杆建议最小值取 0.05～0.1 作为“可画准线”区间，另设“e=0（圆）”按钮或允许 e=0 但隐藏准线。

### 5.8 动画参数化与数值稳健性（统一视角）

**推荐主参数化：极坐标采样**

        r(θ) = l / (1 - e·cosθ),   P(θ) = (r·cosθ, r·sinθ)

| 情形 | θ 定义域 | 处理 |
|---|---|---|
| 0<e<1 | [0, 2π) | 全闭合；分母 ≥ 1-e > 0，无需裁剪（r 有界：r ≤ l/(1-e)） |
| e=1 | (0, 2π)（θ=0 除外） | θ=0 处分母为 0；按视口裁剪：若要求 r≤R，则 θ ≥ arccos(1-l/R)（要求 l<R） |
| e>1 | (arccos(1/e), 2π-arccos(1/e)) | 两端 r→∞；按视口裁剪：cosθ ≤ (1-l/R)/e，再与定义域取交集 |

实现建议：
1. 采样 720～1440 个 θ；逐点计算；若 abs(1-e·cosθ) < ε（如 1e-6）或 r > R_view，**断开折线**（不要连线到无穷远），分段落绘制。
2. **e 跨 1 动画**：固定 l，让 e 从 0.1 连续变化到 3。此时曲线连续地从椭圆变到抛物线再变到双曲线一支；页面只需保证极点 F、准线 x=-l/e、半通径 l 不变即可获得“连续形变”的教学效果。
3. **不要**在 e→1 附近用中心参数化：固定 l 时 a = l/abs(1-e²)、b = l/√abs(1-e²)、c = el/abs(1-e²) 都会发散（e=1±1e-6 时 a≈5×10⁵）。用极坐标直接画，视口以 l 为尺度（如 R_view = 3l～6l）即可。
4. **补画 e>1 的另一支**：用中心对称 (x,y) → (-2c-x, -y)；但注意 c 在 e→1⁺ 时很大，第二支会跑到视口外，可只画第一支并在文案中说明，或用“第二焦点/准线”局部展示。
5. 视口与自动缩放：
   - 统一视角的“自然尺度”是 l；建议 R_view ≈ 3l～5l；
   - e<1 时曲线最右端 x = l/(1-e) 可能远超视口（e=0.95 时为 20l），应允许裁剪并提示“椭圆很扁，右端已超出视野”或提供“适配视野”按钮（但适配后焦点附近会变小）；
   - e>1 时左支最左端 x = -l/(e-1)，e→1⁺ 时也发散，同理处理。
6. 屏幕坐标：x_s = cx + k·x，y_s = cy - k·y，k 两轴相同；在 e 接近 1 时自动换 k 会引起“缩放跳变”，建议动画期间固定 k（或平滑插值）。

### 5.9 其他可用于页面的公式

- 由定义直接得 PF / PD = e（PD 为到准线距离），页面实时显示该比值。
- 由 r = l/(1-e·cosθ) 可得线性关系 1/r = (1 - e·cosθ)/l，即 1/PF 关于 cosθ 是直线——可作为“半通径 l 与 e”的进阶探究活动。
- 半通径端点：(0, ±l) 恒在曲线上（对 e>0），可用于画通径并标注 l。

## 6. 水平/竖直焦点轴总表

| 曲线 | 水平（焦点轴 ∥ x） | 竖直（焦点轴 ∥ y） |
|---|---|---|
| 椭圆 | x²/a²+y²/b²=1，焦点 (±c,0)，准线 x=±a²/c，焦半径 a±e·x | x²/b²+y²/a²=1，焦点 (0,±c)，准线 y=±a²/c，焦半径 a±e·y |
| 双曲线 | x²/a²-y²/b²=1，焦点 (±c,0)，准线 x=±a²/c，渐近线 y=±(b/a)x，焦半径 abs(e·x±a) | y²/a²-x²/b²=1，焦点 (0,±c)，准线 y=±a²/c，渐近线 y=±(a/b)x，焦半径 abs(e·y±a) |
| 抛物线 | y²=2px，焦点 (p/2,0)，准线 x=-p/2，焦半径 x+p/2 | x²=2py，焦点 (0,p/2)，准线 y=-p/2，焦半径 y+p/2 |
| 统一视角 | 焦点在原点，准线 x=-l/e，r=l/(1-e·cosθ) | 焦点在原点，准线 y=-l/e，r=l/(1-e·sinθ)（θ 从 +x 起算） |

> 统一视角竖直版的推导：把 x、y 互换（或把 θ 换成“从 +y 轴起算”），准线为水平线 y=-l/e 时，距离公式中出现的是 sinθ。

## 7. 任意点 P 的距离公式与不变量（动画标签用）

| 模式 | 到焦点距离 | 到准线距离 | 不变量 |
|---|---|---|---|
| 椭圆（水平） | 左 a+e·x；右 a-e·x | (a+e·x)/e；(a-e·x)/e | PF₁+PF₂=2a |
| 椭圆（竖直） | 下 a+e·y；上 a-e·y | 对应 /e | 同上 |
| 双曲线（水平） | 左 abs(e·x+a)；右 abs(e·x-a) | 对应 /e | abs(PF₁-PF₂)=2a |
| 双曲线（竖直） | 下 abs(e·y+a)；上 abs(e·y-a) | 对应 /e | 同上 |
| 抛物线 | x+p/2（竖直 y+p/2） | x+p/2（竖直 y+p/2） | 比值 = 1 |
| 统一视角 | r | r/e（即 abs(x+l/e)） | PF/PD = e |

其他恒等式（可用于 QA）：
- 椭圆：a²=b²+c²，e=c/a，l=b²/a，d=l/e；
- 双曲线：c²=a²+b²，e=c/a，l=b²/a，d=l/e；
- 抛物线：l=p，d=p；
- 统一：a=l/abs(1-e²)，l=b²/a（e≠1），d=dist(F,准线)=l/e；
- 通径（过焦点垂直焦点轴的弦）长度：椭圆/双曲线 2b²/a，抛物线 2p，统一 2l。

## 8. 动画参数化与实现细节汇总

1. **标准模式（A/B/C）**
   - 椭圆：(a·cos t, b·sin t)（竖直 (b·cos t, a·sin t)），t∈[0,2π)；
   - 双曲线：(±a·cosh u, b·sinh u)（竖直 (b·sinh u, ±a·cosh u)），u∈[-U,U]，按视口取 U；
   - 抛物线：(p·t²/2, p·t)（竖直 (p·t, p·t²/2)），按视口裁剪 abs(t)。
2. **统一模式（D）**：极坐标 r=l/(1-e·cosθ)，按 §5.8 的定义域/裁剪处理；e>1 的第二支用中心对称补画。
3. **动点驱动**：用同一个参数 t/u/θ 驱动曲线采样与动点位置，保证动点严格在曲线上；距离用实际坐标的 hypot 计算，再与解析公式比对显示。
4. **等比例画布 + y 轴翻转**：x_s = cx + k·x、y_s = cy - k·y，两轴 k 相同；网格与坐标轴刻度同步。
5. **数值保护清单**：
   - a > 0、p > 0、l > 0 输入校验；
   - c > 0 才绘制准线 x=±a²/c；e=0 特判；
   - 极坐标分母 1-e·cosθ 的零附近断开折线；
   - 大坐标（双曲线远端、e→1 的椭圆右端）裁剪，避免 Canvas 数值抖动；
   - 显示数值保留 4 位有效数字并可四舍五入，避免 0.30000000000000004 之类。
6. **视觉层级**：曲线（实线）> 渐近线（虚线）> 准线（点划线）> 焦点/顶点（实心点）> 动点（高亮）> 距离线段（细线）。
7. **教学联动**：滑杆 a、e（或 p、l）变化时，方程文本、焦点坐标、准线、渐近线、焦半径、不变量数值同步更新；竖直开关同时交换全部几何量。

## 9. 方程识别（教学提醒）

对**没有 xy 项**的一般二次方程

        A·x² + C·y² + D·x + E·y + F = 0

先配方（平移），再按 A、C 的符号判断：

| A、C 情况 | 类型 | 注意 |
|---|---|---|
| A、C 同号且非零 | 椭圆型 | 配方后右端 >0 为椭圆；=0 为一点；<0 为空集 |
| A、C 异号 | 双曲型 | 配方后右端 ≠0 为双曲线；=0 为两条相交直线 |
| A=0 或 C=0 | 抛物型 | **还需**另一个变量的一次项非零；否则为两条平行线/一条线/空集 |
| A=C 且 B=0 | 圆 | 是椭圆的特例（e=0） |

补充判据与注意：
1. **判别式** B²-4AC：<0 椭圆型、=0 抛物型、>0 双曲型（含退化情形；高中教学只需把它作为“快速判断”的提示）。
2. **平移**：(x-x₀)²/a² + (y-y₀)²/b² = 1 等是平移后的标准形式；先配方找中心/顶点，再看类型。
3. **旋转**：若存在 xy 项（B≠0），标准形式需先旋转坐标轴消去 xy 项；高中阶段题目一般已给标准形式或可平移形式，页面只需做“教学提醒”，不必实现任意旋转。
4. **只看平方项符号不够**：x²-y²=0（两条线）、x²+y²=0（一点）、x²+y²+1=0（空集）说明必须结合配方后的右端。
5. **方向判断**：
   - 椭圆：分母大的轴为长轴；x² 分母大为水平焦点轴，y² 分母大为竖直焦点轴；
   - 双曲线：正号项对应的轴为实轴；
   - 抛物线：哪个变量是一次方，开口方向就沿该变量的坐标轴（y²=2px 开口沿 x 轴）。

## 10. 与 Lead 产品计划的对照：需要修正/明确的点

以下逐条对照产品计划表述；✅ 为一致，⚠️ 为需要补充或修正。**模式 A/B/C/D 的公式本身基本正确，主要问题集中在表述与实现细节。**

1. ✅ 椭圆：“中心原点、长轴水平 x²/a²+y²/b²=1 (a>b>0)，定义 |PF₁|+|PF₂|=2a，参数 a、e，c=ae，b=a√(1-e²)，焦点、顶点、准线 x=±a²/c、焦半径、通径” —— 全部正确。补充：通径长 2b²/a，半通径 b²/a。
2. ⚠️ 椭圆：“离心率范围 0≤e<1” —— 正确，**但 e=0 时准线 x=±a²/c 无定义**（c=0，准线在无穷远）。UI 必须特判（隐藏准线/显示“准线在无穷远”），否则出现 Infinity/NaN。
3. ✅ 椭圆：“支持长轴竖直（x/y 交换）” —— 正确。补充：竖直时准线 y=±a²/c、焦半径 a±e·y（下焦点取 +）。
4. ✅ 双曲线：“x²/a²-y²/b²=1，abs(|PF₁|-|PF₂|)=2a，a、e>1，c=ae，b=a√(e²-1)，焦点、顶点、准线 x=±a²/c、渐近线 y=±(b/a)x” —— 全部正确。补充退化条件 2a<2c（e>1）。
5. ⚠️ 双曲线：“支持实轴竖直（x/y 交换）” —— 正确，但**竖直时渐近线是 y=±(a/b)x**（斜率 a/b，不是 b/a）。这是最常见的实现错误之一。
6. ✅ 抛物线：“y²=2px (p>0)，焦点 (p/2,0)，准线 x=-p/2，e=1，参数 p；支持 x²=2py” —— 正确。补充：p 就是焦准距，半通径 l=p，通径 2p。
7. ✅ 统一视角：“焦点 F 在原点，准线 x=-l/e（l>0,e>0），|PF| = e·dist(P,准线)” —— 设置正确。
8. ✅ 统一视角：极坐标方程 —— **核对无误，是 r = l/(1-e·cosθ)（θ 从 +x 轴起算）**，负号正确；直角坐标方程为 √(x²+y²)=l+e·x，即 (1-e²)x²+y²-2elx-l²=0。
9. ✅ 统一视角：“e<1 时为完整椭圆，e=1 时为抛物线” —— 对极坐标 r>0 成立。
10. ⚠️ **统一视角：“e>1 时只有双曲线的一支（要确认是哪一支以及另一支如何由第二焦点/准线得到）”** —— 需修正表述：
    - 若指**极坐标方程 r=l/(1-e·cosθ) 取 r>0 的绘图结果**：成立。画出的支是**与焦点同处准线一侧（x>-l/e）的那一支**（右支），顶点 (-l/(e+1),0)；
    - 若指**焦点—准线定义 |PF|=e·dist(P,准线)**：不成立。定义给出**整条双曲线（两支都满足同一 F、同一准线）**；另一支可用 F'=(-2c,0) 与 ℓ':x=-c-a/e 描述（或以 F' 为极点、极轴取 −x 方向，方程仍为 r=l/(1-e·cosφ)），也可直接关于中心 (-c,0) 作中心对称补画（推荐实现）。
    - 建议页面文案：“极坐标方程取 r>0 时，e>1 只画出含焦点的一支；另一支需补画。”而统一定义页写“e>1 为双曲线（两支）”。
11. ✅ 统一视角：“l 是该曲线的半通径吗？与标准形式关系” —— **是**：l=b²/a（椭圆/双曲线）、l=p（抛物线）、a=l/abs(1-e²)（e≠1）；且 l=e·dist(F,准线)；过焦点垂直于轴的弦半长恒为 l（统一视角下交点为 (0,±l)）。
12. ⚠️ **坐标系原点不一致**：模式 A/B/C 分别以**中心/顶点**为原点，模式 D 以**焦点**为原点；切换模式时曲线位置会跳变。UI 应在画布/标题中明确“原点：中心/顶点/焦点”，不要让学生把 D 中“焦点 (0,0)”与 A/B 中“焦点 (±c,0)”直接对照。
13. ⚠️ **Canvas 等比例与 y 轴翻转**：计划未提及。页面必须 y_screen = cy - k·y 且 kx=ky，否则离心率/焦点/准线/渐近线视觉失真。
14. ⚠️ **统一视角 e→1 的数值稳定性**：固定 l 时 a=l/abs(1-e²)、b、c 都发散（e=1±1e-6 时 a≈5×10⁵）。e 滑杆跨越 1 时**不要用中心/a/b/c 参数化绘图**，应直接用极坐标采样 + 视口裁剪；标准形式仅用于文字展示（并给出正确平移后的方程）。
15. ⚠️ **统一视角“标准方程”展示**：因焦点在原点，椭圆/双曲线的标准方程中心不在原点：椭圆 (x-c)²/a²+y²/b²=1、双曲线 (x+c)²/a²-y²/b²=1、抛物线 y²=2l(x+l/2)。不要显示成“x²/a²+y²/b²=1”，否则学生代入 F=(0,0) 时对不上。
16. ✅ 其他：椭圆焦半径 a±e·x、双曲线焦半径 abs(e·x∓a)、通径 2b²/a/2p，与计划一致（计划仅提“焦半径/通径”，建议在 UI 中给出具体公式与数值）。

## 13. 公式速查

椭圆（水平）：x²/a²+y²/b²=1, c=ae=√(a²-b²), b=a√(1-e²), e=c/a
  焦点(±c,0), 准线 x=±a²/c, 焦半径 a±e·x, 和=2a, l=b²/a
椭圆（竖直）：x²/b²+y²/a²=1, 焦点(0,±c), 准线 y=±a²/c, 焦半径 a±e·y

双曲线（水平）：x²/a²-y²/b²=1, c=ae=√(a²+b²), b=a√(e²-1), e=c/a>1
  焦点(±c,0), 准线 x=±a²/c, 渐近线 y=±(b/a)x, 差绝对值=2a, l=b²/a
双曲线（竖直）：y²/a²-x²/b²=1, 焦点(0,±c), 准线 y=±a²/c, 渐近线 y=±(a/b)x

抛物线（水平）：y²=2px (p>0), 焦点(p/2,0), 准线 x=-p/2, e=1, l=p, 通径 2p
抛物线（竖直）：x²=2py (p>0), 焦点(0,p/2), 准线 y=-p/2, e=1, l=p

统一视角：F=(0,0), 准线 x=-l/e, 定义 PF=e·PD
  极坐标 r=l/(1-e·cosθ)  (θ 从 +x 轴起算)
  直角坐标 √(x²+y²)=l+e·x  ⇔  (1-e²)x²+y²-2elx-l²=0
  e<1: 椭圆, a=l/(1-e²), b=l/√(1-e²), c=el/(1-e²), 中心(c,0)
  e=1: 抛物线 y²=2l(x+l/2), 顶点(-l/2,0), p=l
  e>1: 双曲线, a=l/(e²-1), b=l/√(e²-1), c=el/(e²-1), 中心(-c,0)
       渐近线 y=±√(e²-1)(x+c); 极坐标 r>0 只画含焦点一侧的一支
  l = 半通径 = b²/a (e≠1) 或 p (e=1) = e·dist(F,准线)
