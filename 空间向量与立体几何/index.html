用空间向量解决立体几何问题

把几何对象放进空间直角坐标系，用向量表示直线的方向和平面的法向，再用线性运算、数量积与坐标运算判断位置关系、计算角度和距离。

空间向量把“作辅助线”变成“算坐标”。判断平行与垂直看共线与数量积；求角度看方向向量与法向量；求距离看投影与叉积。

a · b = a₁b₁ + a₂b₂ + a₃b₃
01

线性运算

AB + BC = AC

三角形法则首尾相接；平行四边形法则共起点作对角线。加法满足交换律、结合律，数乘满足分配律。

02

基本定理

v = x e₁ + y e₂ + z e₃

若 e₁、e₂、e₃ 不共面，则空间中任意向量 v 都能唯一表示成它们的线性组合。

03

坐标表示

AB = (x₂−x₁, y₂−y₁, z₂−z₁)

向量坐标等于终点坐标减起点坐标；模长 |a| = √(a₁²+a₂²+a₃²)。

04

数量积

a · b = |a||b|cos θ

a·b = 0 ⇔ a ⊥ b（非零向量）；cos θ = a·b/(|a||b|)，θ ∈ [0°, 180°]。

05

方向与法向

n · d = 0 ⇔ l ∥ α

直线的方向向量 d 与平面的法向量 n：平行于平面看 n·d=0，垂直于平面看 d∥n。

06

平行与垂直

a × b = 0 ⇔ a ∥ b

线线：方向向量共线或数量积为 0；线面：n·d=0 或 d∥n；面面：法向量共线或数量积为 0。

07

空间角

sin θ = |d · n|/(|d||n|)

异面直线角用 |cos|；线面角用 sin；二面角可转化为两平面法向量的夹角或其补角。

08

空间距离

d = |n · AP| / |n|

点面距用投影；点线距用 |AP × d|/|d|；两平行平面距可转化为点面距。

常见易错点

  • 线线角取锐角。用 |a·b|/(|a||b|) 求异面直线所成角，结果在 [0°,90°]。
  • 线面角用 sin。sin θ = |d·n|/(|d||n|)，θ ∈ [0°,90°]，不要与向量夹角混淆。
  • 二面角可能是钝角。用法向量求出的角要与实际图形对照，必要时取补角。
  • 法向量不唯一。一个平面的法向量可以相差非零倍数，通常取最简整数比。
  • 平行不一定重合。线面平行要求直线不在平面内，需另取点验证。
  • 向量夹角范围是 [0°,180°]，与直线所成角、线面角的范围不同。

课堂演示路线

  1. 01 播放 a+b+c 的合成，观察三条棱向量如何得到体对角线。
  2. 02 调 x、y、z，看斜基底下的平行六面体与唯一分解。
  3. 03 拖动 P 的坐标，比较 OP 的坐标与模长。
  4. 04 调节 b 的方向，观察数量积、夹角与投影的联动。
  5. 05 切换线 AC 与 BD₁，比较 n·d 的符号与线面位置关系。
  6. 06 逐个切换四条结论，先看几何，再看向量运算。
  7. 07 切换异面直线、线面角、二面角，比较三种角的公式。
  8. 08 对比点面距与点线距，理解投影与叉积的几何意义。

空间直角坐标系

以正方体的顶点 A 为原点，三条棱 AB、AD、AA₁ 所在直线分别为 x、y、z 轴，建立右手直角坐标系。则 A(0,0,0)、B(1,0,0)、D(0,1,0)、A₁(0,0,1)、C₁(1,1,1)。

空间中两点 P₁(x₁,y₁,z₁)、P₂(x₂,y₂,z₂) 的距离为 √((x₂−x₁)²+(y₂−y₁)²+(z₂−z₁)²)。

角与距离的统一思路

线线角、线面角、二面角都可以转化为两个向量的夹角：线线看方向向量，线面看法向量与方向向量，二面角看两个法向量。

距离则统一为“斜向量在法向量方向上的投影”：点面距 |n·AP|/|n|，点线距 |AP×d|/|d|，两平行平面距 |n·AP|/|n|。
